# Подготовка Берёзовки — 2026-11-11

Карта: /Game/FinalCoil/Maps/L_Berezovka_Blockout.
Назначена стартовой картой проекта.
Исходный план: SourceArt/Maps/Berezovka_PreAlpha_v1.png.

Использован только нижний увеличенный план села, область изображения
x=12..972, y=600..940. Верхняя региональная схема имеет другой масштаб.
Линейка: (35,632)..(190,632), 155 пикселей = 200 м.
1 пиксель = 129.032258 см. Размер подложки 1238.71 × 438.71 м.
Масштаб приблизительный: исходник рисованный, с перспективными условностями.

Начало координат соответствует (457,837) исходного изображения у STOP-01.
PlayerStart_STOP01_Temporary: (0,0,110) см, поворот 90°.
Север +X, восток +Y. Плоскость Z=0, коллизия BlockAll.
Материал без освещения, UV вычисляются из мировых координат:
U=(Y/129.032258+457)/1280; V=(-X/129.032258+837)/960.
Подложку не перемещать без пересчёта формул материала.
Папка 00_Reference содержит подложку и контрольные точки линейки.
Дома, дороги как геометрия, Landscape и рельеф не создавались.

Проверено через UE Python: карта сохранена и загружена заново,
один PlayerStart, контрольное расстояние 20000 см.
Отчёт: Scripts/Berezovka_validation.json.
Визуальная проверка в редакторе и PIE пока не выполнены.
Commandlet завершился с кодом 1 из-за ранее известной ошибки общего DDC;
скрипт создания карты завершён успешно (BEREZOVKA_LEVEL_OK).
Для запуска при недоступном DDC: ./LaunchEditor.ps1 -MemoryCache.
