# FINAL COIL — этап 1 природного окружения

Дата: 13.11.2026. UE 5.8.4, ветка dev.

## Результат

Реализован единый расчёт десяти зон, адаптер текущего Static Mesh Terrain, конфигурация групп растений, защитные маски, девять PCG-областей и отдельный мировой диагностический обзор. Финальные растения не добавлялись. Исходная игровая геометрия сохранена.

## Что использовано повторно

- `terrain_profile.py`, актуальный `Terrain/heightfield.json` и треугольная сетка нынешнего SM_HeroForestTerrain.
- Неизменённые Biome/Use PNG и world-space bounds из GroundMaterial/mask_manifest.json.
- CompactVillage/plan.json: дороги, тропы, все H01–H14/E01–E11/G01 и площадки.
- Terrain/manifest.json и первоначальные Forest/OldBor/Lake masses для региональных зон.
- Существующие PCG, Python Editor Scripting, MCP и проверки репозитория. CompactVillage/plants.json и VillagePlants/planting.json исследованы; существующая растительность сохранена.

## Связь с PCG и локальный пересчёт

`environment_zones.py` формирует world-anchored точки с нормалью, уклоном, влажностью, PlotID, десятью весами, исключением и плотностями групп. `install_environment_zones.py` сохраняет их в PCGDataAssets через UE API. Мастер-граф загружает девять областей, объединяет метаданные и фильтрует Exclusion. В реальном выходе проверено **8 116 точек, 0 нарушений исключений**. Поверхность/маски рассчитаны предварительно; нативное Landscape Layer Sampling для меша не используется.

Регенерация: Tools → FINAL COIL — Environment Zones → Rebuild stop/G01 либо `environment_editor.regenerate("stop")`. Импорт использует SHA и не создаёт дубликаты. Мировой обзор не поступает в PCG; пересекающиеся окна получают единственного владельца точки. Повторный пересчёт stop дал те же точки/seed и оставил остальные JSON побайтно неизменными.

## Проверки UE, масштаба и коллизии

- 19 исходных проверок прошли: координаты/масштаб масок, pixel centres, нормализация весов/нормалей, исключения воды/дорог/строений, E02, отключение зоны, ручные override, контракт Landscape adapter, детерминизм и локальная регенерация.
- Сравнение до/после подтвердило полное совпадение исходных 937 actors по трансформациям, мешам, материалам, коллизии и instance count.
- 52 трассировки по реальному terrain: максимальная ошибка высоты 0.00009557 см; минимальный dot нормалей 0.99999089. Проверена в том числе геометрия озёрной котловины.
- 26 участков по 1 000 м² и исходная калибровка схемы 140 м подтверждены repository checks. Текущее расстояние до перенесённого дома героя около 283.9 м; оно не возвращалось к старому.
- PIE: остановка (подход по главной дороге) → открытые ворота → гараж G01 → обратно: **passed, 33/33 точек**, примерно 666.9 м. Движение реальным CharacterMovement, телепорт только для начального появления; скорость теста 4 м/с.
- Отдельный повторный проход каждого старого маршрута к Старому Бору и берегу не проводился; их неизменность подтверждена сравнением всех прежних коллизий. Полный пользовательский обход остаётся полезным перед следующим выпуском.
- Map Check после загрузки: 0 errors / 0 warnings. Отладочный материал компилируется и виден в редакторских кадрах; реальное выполнение PCG и PIE завершились. Ошибки ранних итераций импорта устранены; промежуточные логи остаются только в ignored Saved.

## Производительность

ПК по логам UE: i5-12400F, GTX 1660 (5966 MB dedicated VRAM), 32621 MB RAM, Windows 11 22H2, D3D12 SM6. Сравнение пяти одинаковых ракурсов, 90 кадров прогрева + 301 CSV кадр на ракурс. Реальный embedded PIE viewport **1014×550**, несмотря на ResX/ResY. Дополнительное плавающее PIE ограничилось **1280×722**. Цель 60 FPS / 1920×1080 **не подтверждена**.

RenderThreadTime в CSV почти нулевой (0.000–0.003 мс) и непригоден как полная стоимость Render Thread. Нужен Unreal Insights в изолированном запуске. Замеры exploratory: открытый второй редактор и различный прогрев кэшей мешают приписывать разницу системе зон. **Ускорение не заявляется**. GPU local used memory в исходных ракурсах примерно 3.3–4.5 ГБ, точные значения в CSV/JSON.

Исходная сцена: 937 actors / 860 StaticMesh components / 286 611 instances. После: 949 / 870 / 298 407. Добавлено 10 редакторских HISM с 11 796 отладочными отсчётами; они HiddenInGame, editor-only, NoCollision и по умолчанию выключены. Runtime PCG не включён. Полный расчёт источников около 3 с; локальный stop 0.3–0.6 с; импорт/сборка отладки около 11–13 с. Это стоимость нынешних тестовых областей, не оценка финального леса.
