# FINAL COIL — луговая растительность, этап 2

13.11.2026 · Unreal Engine 5.8 · ветка dev · `/Game/FinalCoil/Maps/L_Berezovka_Terrain`.

## Результат и границы приёмки

Реализован ограниченный визуальный прототип: пять групп, 18 оригинальных вариантов геометрии, плотное детерминированное распределение, связанный PCG-граф, сохранённые HISM, ветер, три режима качества и редакторское меню. Рабочий Medium: **25 913 пучков**. Генерация на остальную карту не распространялась.

**Художественная приёмка остаётся открытой.** Покров стал объёмным и многослойным, но земля в просветах слишком гладкая, некоторые силуэты пучков заметны, а дальний фон ещё выглядит черновым. Это не объявляется готовым фотореалистичным российским лугом только на основании работающего PCG. 60 FPS также не достигнуты: исходная сцена без новой травы уже ограничена GPU.

## Производительность

Тестовый ПК: i5-12400F, GTX 1660 6 GB, 32 GB RAM, Windows, D3D12 SM6. Отдельный `UnrealEditor -game -RenderOffscreen`, исходный уровень/свет/базовые renderer settings, ScreenPercentage=100, VSync=0, dynamic resolution=0, foreground idle=0. Это standalone uncooked, не packaged build. Изменялись только настройки новой травы.

Внутри каждого запуска два одинаковых цикла скрыть/показать только `MEADOW_Output`. Старые растения остаются в обоих состояниях. Первый цикл служит прогревом; итог — по 200 кадров второго цикла, строки CSV 1350–1549 и 1800–1999. Перед выборками достаточно времени на завершение screenshot/readback. CSV подтверждает одинаковые положение и направление камеры до/после; камера примерно `(18000, 29586.54, 279.37)` см. Редактор во время теста ограничен до 1 FPS. Другие пользовательские приложения не закрывались.

FPS вычислен из среднего CSV FrameTime, не из Slate dt. p95 кадра после: Low 32.64 мс, Medium 34.07 мс, High 34.30 мс. Дополнительное время кадра: **+2.46 / +3.37 / +4.16 мс** соответственно. Количество draw calls не обязано монотонно следовать числу instances: HISM распределяется по LOD/секциям и нескольким проходам. В данном замере Low имеет больше calls, но меньше времени GPU.

RenderThreadTime здесь — измеренное время потока вместе с ожиданиями, почти равное времени GPU-ограниченного кадра. Это **не** чистая CPU-стоимость Render Thread; для её выделения нужен Insights. LocalUsedMB измеряется при уже резидентных ресурсах обоих состояний. Visibility A/B не изолирует дополнительную память ассетов: почти нулевую разницу нельзя выдавать за отсутствие стоимости VRAM.

Основное ограничение — GPU: около 27,3–27,6 мс ещё до новой травы при Game Thread около 3 мс. Понижение плотности помогает на несколько миллисекунд, но не превращает этот renderer в 60 FPS. В `performance.json` сохранены GPU-проходы; дорогими остаются Lumen Screen Probe Gather, TSR, освещение и исходная сцена. Глобальные свет/renderer ради целевой цифры не упрощались.

Первый исследовательский Medium запуск дал нестабильный результат из-за условий прогрева/фонового режима. Он не используется как итог и не служит основанием заявлять ускорение. Плавающий PIE ограничился 1920 × 994; его FPS в таблицу не попал.

## Архитектура и настройки

Конфигурация: `SourceArt/MeadowVegetation/config.json`, bounds `[15500,27500,20500,32500]` см, seed 4122026. Участок ровно 50 × 50 м внутри прежней `meadow`, Z04=1 на проверенных отсчётах, перепад высот около 66 см. Новых корней вне bounds нет. Краевая маска плавная и нерегулярная, полоса около 6,5 м.

Непрерывные случайные XY → шум нескольких масштабов / группы → Z04 × GrassDensity × влажность / уклон / дороги → исключения → min-distance → точная поверхность → PCG data assets → нативный mesh-by-attribute spawner → HISM. Диагностическая сетка не используется как схема размещения. Потоки групп независимы, seed повторяем, качества вложены друг в друга. Первый этап сохраняется.

Меню **Tools → FINAL COIL — Environment Zones** дополнено перестроением, видимостью, качеством, ветром и standalone benchmark. Подробная настройка из Python Console — в [заметке Obsidian](../../../obsidian-doc/05%20Разработка/48%20Луговая%20растительность%20и%20PCG.md). Один конфиг регулирует общую/групповые плотности, высоту/ширину, seed, размеры пятен, min-distance, fade и качество.

Сохранён один новый `MEADOW_Output`. Исходный редакторский PCG actor не превращён в игровой. Ветер — GPU WPO с единым `MPC_MeadowWind.WindStrength` и разной амплитудой групп; основание закреплено множителем высоты². Материал земли сохранён. Цветки приглушены, сухие растения локальны. Физика травы не добавлялась.

## Проверки и сохранность

- 14 новых проверок источников — passed: детерминизм, отдельная группа, пять групп, min-distance, вариации, отсутствие привязки к диагностической сетке, вложенность качеств, граница и корни.
- 19 прежних проверок зон — passed; stop regenerated с changed=false, соседние JSON идентичны. Новый результат прогона сохранён отдельно, прежний отчёт первого этапа не переписан.
- 949 прежних actors/components — без изменений трансформаций, meshes, материалов, коллизии и instance count. Хэши исходных EnvironmentZones, Masks и VillagePlants совпали.
- 25 трассировок по реальному terrain — максимальная ошибка **0.000045 см**. Корни источников совпадают с адаптером в пределах **0.000051 см**, заглублены на 0,5 см.
- В живом выходе мастера: **8116 прежних диагностических + 25913 новых плотных точек**, 0 нарушений Exclusion. `GenerateOnDemand`.
- Все **25 старых узлов и 24 связи** мастера сохранены без изменений; добавлена одна ветвь subgraph. [graph_validation.json](graph_validation.json).
- Map Check: **0 ошибок / 0 предупреждений**. Мелкая трава NoCollision, HISM, без теней.
- PIE: персонаж прошёл пять контрольных точек через участок реальным CharacterMovement, без телепортов между точками. Телепорт использован только для начального появления. [PIE_walk.json](PIE_walk.json).
- Ветер отключается единым параметром и восстанавливается; общий параметр проверен в редакторе. Математически WPO корней равен нулю. Покадровое измерение амплитуды каждого вида отдельно не выполнено.
- Проверка структуры репозитория и синтаксиса Python — passed. Сохранены игровые ассеты; временные очереди, логи, резервные копии и кэши находятся только в ignored Saved.

## Открытая часть приёмки

- [x] Пять групп, 18 вариантов, видимость в PIE и отдельном игровом процессе.
- [x] Группы, переменная высота, отсутствие квадратной сетки, плавное снижение плотности.
- [x] Корректная поверхность, запреты, повторяемость, локальное перестроение, NoCollision.
- [x] Low/Medium/High, GPU-ветер с выключением, реальные кадры и Full HD метрики.
- [x] Сохранность исходного мира, запуск PIE, свободный проход.
- [ ] Финальная художественная реалистичность: грунт в просветах, узнаваемость повторяющихся пучков, естественность дальнего покрова и некоторых видов требуют доработки. Прототип не объявлен окончательно готовым.
- [ ] Полная визуальная приёмка отсутствия pop на длинном движущемся маршруте: fade/LOD настроены, но систематический видеопроход 0–65 м не снят.
- [ ] 60 FPS — не достигнуто, GPU-ограничение имеется и в контроле без новой травы.
- [ ] Чистое busy CPU время Render Thread и изолированный прирост VRAM требуют отдельного профиля.
- [ ] В uncooked `-game` логах имеются ошибки инициализации редакторских toolset-плагинов (отсутствующие ToolsetDefinition/PythonTestRunner). Игровые процессы завершились с кодом 0 и выдали проверенные кадры/CSV; чистый packaged startup отдельно не подтверждён.
- [ ] Переход через реальную обочину не принят; добавление второй полосы не потребовалось для внутренней мозаики высот.

## Исследованные внешние альтернативы

Проверены [Grass Medium 01](https://polyhaven.com/a/grass_medium_01) и [лицензия Poly Haven](https://polyhaven.com/license): CC0 допускает использование и распространение исходных ассетов. Страница модели указывает 2M triangles для исходного набора. Он потребует подготовки игрового LOD/atlas и проверки overdraw; прямой массовый импорт непригоден. В этот прототип внешние ассеты, изображения, лицензированные библиотеки или платные зависимости не добавлены.

Дальнейший шаг — художественная оценка этого участка и доводка крупного плана. До неё не заполнять растительностью весь мир.
