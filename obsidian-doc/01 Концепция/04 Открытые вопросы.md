# Открытые вопросы

## P0 — определяют всю игру

- [ ] Утвердить регион: русский Север / Карелия / Урал / Сибирь / иной.
- [ ] Определить правдоподобную процедуру наследства и скорость раннего отъезда (бумаги, автобус, связь).
- [ ] Найти долгосрочный ежедневный цикл без искусственного фарма.
- [ ] Решить, какие действия и объекты гарантированно доступны игроку без автомобиля.
- [ ] Выбрать размер и топологию карты после прототипа ходьбы/поездок.
- [ ] Зафиксировать производственный минимум «интересно уже сейчас» для первой публичной демоверсии.

## P1 — нужны после первого прототипа

- [ ] Утвердить модель/модификацию машины и технический уровень разборки.
- [ ] Продумать деньги, покупки, работы, продажу дома и непротиворечивую экономику.
- [ ] Определить 4–6 самостоятельных расследований: их входы, улики, исходы.
- [ ] Расписать 5–6 жителей: распорядок, мотивы, точки зрения, ограничения.
- [ ] Выбрать подход к смерти/провалу, сохранениям и восстановлению застрявшей машины.
- [ ] Определить диапазон времени, календарь, сон и автобусное расписание.

## P2 — отложить

- [ ] Радиостанции, охота, сторонние подработки, сложная симуляция кузова и жидкости.
- [ ] Полный физический домкрат с опрокидыванием; сначала проверить дешёвый прототип.
- [ ] Кооператив/мультиплеер, большой список модификаций, множество машин.
