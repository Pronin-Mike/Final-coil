# Техническая архитектура (проектные предложения)

Ниже — **план** для новой песочницы, а не заявление, что это уже реализовано.

## Базовые модули

1. **Player + Interaction:** Line Trace, выбор объекта, контекстные действия, переноска.
2. **Inventory / ItemDefinition:** тип предмета через Data Asset, состояние конкретного экземпляра — отдельно.
3. **CarAssembly:** слоты, зависимости, крепёж и диагностика состояния агрегатов.
4. **WorldState:** состояние домов, доступных предметов, ремонта, отношений и расследований.
5. **InvestigationJournal:** факты, свидетельства, гипотезы, точки на карте.
6. **Time & Weather:** внутриигровое время, погода, NPC-расписания и транспорт.
7. **SaveGame:** персонаж + отдельные экземпляры предметов + машина + сюжетные/мировые флаги.

## Данные деталей — ключевое архитектурное замечание

В старой заметке в `BP_CarPartData` одновременно лежат **свойства типа** (`PartName`, `PartType`) и **состояние экземпляра** (`Condition`, `IsInstalled`). Нужно проверить и, при необходимости, разделить: общие данные в Data Asset, изменяемые данные экземпляра в Actor/компоненте/структуре сохранения. Иначе две одинаковые детали могут ошибочно делить состояние.

## Система соединений

Предлагаемая минимальная модель:

`PartDefinition` → `PartInstance` → `AssemblySlot` → `FastenerStates` → `SystemHealth / Eligibility`.

В прототипе не рассчитывать все реальное механическое взаимодействие сразу. Игроку нужны понятные действия и наблюдаемая причина неудачи.

## Сохранение

Сохранить идентификатор экземпляра, локацию, состояние деталей/креплений, объекты мира, время, журнал наблюдений и результаты действий. Откат неконсистентной физики и застрявших объектов — отдельная задача.

## Риски

- Отдельная физика десятков деталей + автомобиль + NPC + открытый мир в UE5 может оказаться дороже, чем написание сюжетного контента.
- Не реализовывать всю механику домкрата в начале, пока не протестирована устойчивость.
- Для раннего вертикального среза лучше проверить **один** полноценный автомобильный узел и **одну** короткую историю исследования.
