# Синхронизация FINAL COIL

Репозиторий: https://github.com/Pronin-Mike/Final-coil

Рабочая ветка — **dev**. **master** обновляется только слиянием Pull Request из dev. Старый main сохранён как история сайта.

## Перед работой на другом компьютере

1. На предыдущем компьютере сохранить уровень, закрыть Unreal, выполнить **Git: Commit-and-sync**.
2. На этом компьютере закрыть Unreal, открыть Obsidian и выполнить **Git: Pull** (`Ctrl+Shift+U`).
3. Дождаться завершения загрузки, затем открыть `.uproject`.

## Отправить изменения

Сохранить уровень, закрыть Unreal. Нажать **Ctrl+Shift+S** — Git: Commit-and-sync. Коммит включает проект и заметки. Дождаться успешного push; изменения отправляются в dev.

Вместо горячей клавиши: `Ctrl+P` → `Git: Commit-and-sync`. Только локальный коммит: `Git: Commit all changes`; отправить уже созданные коммиты: `Git: Push`.

## Получить изменения

Сначала сохранить свои изменения коммитом и закрыть Unreal. **Ctrl+Shift+U** — Git: Pull. Дождаться завершения Git LFS. Не открывать уровень во время загрузки ассетов.

Если ветки разошлись или возник конфликт, остановиться. Не выбирать «перезаписать всё», не выполнять reset/force push. Локальные коммиты остаются сохранены. Markdown можно объединить вручную; для `.umap` и `.uasset` нужно выбрать корректную версию файла.

## Первый запуск после клонирования

Клонировать dev средствами Git, выполнить `tools/Setup.ps1`, открыть **obsidian-doc** как хранилище. При необходимости перезапустить Obsidian для загрузки настроек и горячих клавиш. На другом компьютере может потребоваться вход в GitHub средствами Git.

Хранилище должно оставаться внутри полного клона проекта. Не копировать только папку заметок отдельно: она использует Git-корень на уровень выше. На текущем компьютере открыт весь `D:/GameDevelop` как хранилище **GameDevelop**; для него также сохранены Git-плагин и обе горячие клавиши в корневой `.obsidian`.

## Выпуск в master

Создать на GitHub Pull Request **dev → master**, дождаться проверок и выполнить Merge. После выпуска на рабочем компьютере получить dev; после последующих собственных изменений отправлять снова в dev.

GitHub Pages публикует справочник из master. Проект UE и заметки доступны в репозитории, но не копируются в артефакт сайта.
